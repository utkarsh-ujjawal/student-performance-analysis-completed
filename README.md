# Student Performance Analysis System

## 📌 Project Overview

The Student Performance Analysis System is a Python-based project that analyzes student marks and attendance using Pandas and visualizes student performance using Matplotlib.

## 🎯 Objectives

* Display student records.
* Calculate total and average marks.
* Identify the class topper.
* Calculate the class average.
* Analyze student Pass/Fail results.
* Analyze attendance percentages.
* Identify students with attendance below 75%.
* Generate a bar chart of student performance.
* Save analyzed results in a CSV file.

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* CSV

## 📂 Project Files

* `main.py` — Main Python program.
* `students.csv` — Input dataset containing student information.
* `analysis_results.csv` — Output file containing analyzed results.
* `student_performance.png` — Generated performance chart.
* `README.md` — Project documentation.

## ⚙️ Installation

Install the required libraries using:

```bash
pip install pandas matplotlib
```

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python main.py
```

4. View the analysis results in the terminal.
5. Check the generated graph and CSV output files.
